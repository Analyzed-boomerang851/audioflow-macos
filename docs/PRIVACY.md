# AudioFlow Privacy Policy

Last updated: August 13, 2026

AudioFlow is a local-first macOS application. It does not include analytics, advertising, crash-reporting SDKs, accounts, cloud synchronization, or network services.

## System Audio Recording permission

AudioFlow uses the macOS System Audio Recording permission to discover applications producing audio and to apply per-app volume, mute, gain, and output-routing controls. Audio data is processed in memory in real time.

AudioFlow does not:

- create audio recordings;
- save captured audio to disk;
- upload or transmit audio;
- collect usage or diagnostic telemetry; or
- sell or share personal information.

## Local settings

Preferences such as theme, language, favorites, ordering, and custom backgrounds are stored locally on the Mac. A custom background image selected by the user is copied into the app's local support storage and is never uploaded.

## Removing access and data

System Audio Recording permission can be changed in **System Settings → Privacy & Security → Screen & System Audio Recording**. Local application data can be removed by deleting AudioFlow's preferences and application-support files.

## Changes

Material privacy changes will be documented in this file and in the release notes.

# AudioFlow 1.0.0

The first public release of AudioFlow, a free and open-source native macOS audio mixer built as a Starry Vibe Coding project.

## Highlights

- Control system output volume and mute state through Core Audio.
- Discover active audio processes and manage per-app volume and mute state.
- Route individual apps to available output devices.
- Use AudioFlow from a compact menu bar controller.
- Organize apps with favorites, media categories, collapsible groups, and custom ordering.
- Choose system-following, light, or dark appearance with optional custom backgrounds.
- Use the interface in Simplified Chinese, English, Japanese, French, German, or Korean.
- Keep all audio processing local and in memory.

## Installation

1. Download `AudioFlow.dmg` below.
2. Open the disk image and drag AudioFlow into Applications.
3. Launch AudioFlow and grant System Audio Recording permission when macOS asks for it.

This community build is ad-hoc signed and is not Apple-notarized. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway**. See the README for source-build instructions.

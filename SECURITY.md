# Security Policy

## Supported versions

Security fixes are provided for the latest published version of AudioFlow.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on this repository instead.

Include a concise description, affected version, reproduction steps, potential impact, and any proposed mitigation. Do not include real captured audio, private device identifiers, certificates, or credentials.

You can expect an initial response within seven days. Confirmed issues will be coordinated privately until a fix is available.
